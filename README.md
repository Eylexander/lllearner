# LLLearner

A personal Android app, written in Flutter, to learn the two languages of Taipei from French:
**Taiwanese Hokkien** (台語, Tâi-lô) and **Taiwan Mandarin** (華語, pinyin and zhuyin).

- **Two decks, side by side**: study one language or both. Cards alternate, and each word shows its equivalent in
  the other language (多謝 to-siā ↔ 謝謝 xièxie).
- **Native audio**: Taiwanese words and example sentences play the recordings of Taiwan's Ministry of Education
  dictionary, downloaded once and cached. Mandarin uses the phone's zh-TW voice.
- **A dictionary**: about 16,800 Taiwanese words (3,700 with French translations, the rest with the Ministry's
  Mandarin definition), 6,900 Mandarin words, and 16,000 example sentences.
- **Spaced repetition** flashcards, quizzes, and a daily streak.
- **Claude as a tutor**: the app opens the Claude app with a prompt built from your progress (lessons, role-plays,
  corrections). Sharing Claude's reply back to LLLearner imports the new words. It uses your Claude subscription;
  there's no API key.

Requires Android 8.0 or newer. The only network access is downloading the Ministry's audio recordings.

## Build

```sh
flutter build apk --release --target-platform android-arm64
# -> build/app/outputs/flutter-apk/app-release.apk
```

Release builds are signed with the release key in `.secrets/` (git-ignored, back it up). Without it, they fall back
to the debug key.

The word database (`assets/dict.db`) and the rare-character font are generated by `tool/build_words.py`; see its
docstring for the sources.

## Releasing

Push a `v*` tag (`git tag v1.0.0 && git push origin v1.0.0`). The "Release APK" workflow runs the analyzer and the
tests, builds the APK signed with the release key from the `RELEASE_KEYSTORE_BASE64` / `RELEASE_KEYSTORE_PASS`
secrets, and publishes it as a GitHub release. The version name comes from the tag and the versionCode from the run
number. The app is distributed through [Eylexander/fdroid](https://github.com/Eylexander/fdroid), which picks up new
releases within 6 hours.

The secrets hold `.secrets/release.p12.b64` and `.secrets/password.txt`. Every release must be signed with this same
key, or phones refuse the update.
