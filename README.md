# LLLearner

A personal Android app, written in Flutter, to learn languages from French. It is built around courses, like the
big language apps; the first (and for now only) course is **Taiwan Mandarin** (華語: traditional characters, pinyin and
zhuyin, Taiwan vocabulary and pronunciation).

- **Lessons**: the course is a path of short lessons (six words). Each new word is introduced with its characters,
  tone-colored pinyin or zhuyin, audio (normal and slow), and an example sentence, then practised right away
  (meaning, recall, listening, tones). Missed questions come back before the end of the lesson.
- **Spaced repetition**: learned words come back in reviews just before you would forget them.
- **Practice** that only asks about words you have already learned: mixed quiz, listening, tones, weak points.
- **A dictionary** of about 6,900 words (hand-picked essentials, then the TOCFL levels) with 7,000 example sentences.
- **Material You**: follows the wallpaper colors on Android 12+ (or a chosen accent), light and dark mode, themed
  launcher icon.
- **Claude as a tutor**: the app opens the Claude app with a prompt built from your progress (tailored lessons,
  role-plays, corrections, short stories). Sharing Claude's reply back to LLLearner imports the new words as your next
  lessons. It uses your Claude subscription; there's no API key.

Requires Android 8.0 or newer and works offline. Audio uses the phone's text-to-speech; install the "Chinese
(Taiwan)" voice if the app says it's missing.

## Build

```sh
flutter build apk --release --target-platform android-arm64
# -> build/app/outputs/flutter-apk/app-release.apk
```

Release builds are signed with the release key in `.secrets/` (git-ignored, back it up). Without it, they fall back
to the debug key.

The word database (`assets/dict.db`) is generated by `tool/build_words.py`; see its docstring for the sources.

## Releasing

Push a `v*` tag (`git tag v1.0.0 && git push origin v1.0.0`). The "Release APK" workflow runs the analyzer and the
tests, builds the APK signed with the release key from the `RELEASE_KEYSTORE_BASE64` / `RELEASE_KEYSTORE_PASS`
secrets, and publishes it as a GitHub release. The version name comes from the tag and the versionCode from the run
number. The app is distributed through [Eylexander/fdroid](https://github.com/Eylexander/fdroid), which picks up new
releases within 6 hours.

The secrets hold `.secrets/release.p12.b64` and `.secrets/password.txt`. Every release must be signed with this same
key, or phones refuse the update.
